# Security and Data Exposure

This repository contains documentation and templates only. It ships no application, no
service, and no dataset. The security concern that matters here is therefore not software
vulnerabilities — it is the **confidential survey dataset** that candidates receive
separately.

## Report an exposure immediately

**Contact: office@youngaileaderslinz.at**

Write to us straight away if any of the following happens, or if you think it might have:

- The dataset was pushed or uploaded to a public repository, gist, or file share
- A link containing the data, your analysis, or your findings was shared or made public
- The data was pasted into a public or shared AI session, forum, or support ticket
- The dataset was sent to the wrong recipient
- A device or account holding the dataset was lost, stolen, or compromised

Please include, as far as you know it: what was exposed, where, roughly when, whether it
is still accessible, and what you have already done about it. A rough account sent now is
far more useful than a precise one sent tomorrow.

**Reporting an incident promptly is treated as responsible handling, not as a failure.**
What causes harm is an exposure nobody hears about. We would much rather help you contain
something quickly than discover it later.

If you have already made something public, do not wait until you have cleaned it up before
telling us. Tell us first, then clean up — deleting a public repository does not always
remove the content immediately, and we can advise on what else is needed.

## What we will do

We will acknowledge your report, work out with you what needs to happen to contain it,
and notify the study's supervisors if the exposure warrants it. We will not publicise
your name in connection with an incident you report.

## Problems with this repository

For a broken link, an error in the documentation, or a mistake in the data dictionary,
email **office@youngaileaderslinz.at**. These are not urgent and do not need to follow the
process above.

## Please do not

- Open a public GitHub issue describing an exposure — that can make the problem worse
- Include actual data rows, screenshots of the data, or personal information in your report
- Attempt to test the security of Young AI Leaders systems or accounts

The full set of obligations attached to the dataset is in [DATA_USE.md](DATA_USE.md).
